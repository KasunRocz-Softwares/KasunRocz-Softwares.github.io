// 03 — How we build

Three laws of this universe.

01

Your data stays yours

No account, no tracking, no cloud sync. If an app goes online, it says why, and you can switch it off.

02

Source on GitHub

Every project is open source under MIT or AGPL. Read it, build it, fork it, send a fix.

03

Made for real use

Glove-sized buttons on the bike, one-click calibration on the PC. Built for the hardware people actually have.

// 04 — Vision

The future we're building is quiet. Software that lives on the hardware you already own, keeps your data where it belongs, and stays open for anyone to read, fork and fix.
